Predictive Intelligence Onboarding Runbook

A formal access and sign-in guide for the Deloitte Predictive Intelligence project.

Runbook focus Access requests, sign-in actions, and status recording

Purpose

Use this runbook to organize the supplied onboarding access and sign-in actions for the Deloitte Predictive Intelligence project.

Intended audience

People onboarding to the Deloitte Predictive Intelligence project who need to complete the listed actions.

Request and contact note

Action checklist

Onboarding sequence

Work through the supplied actions and use the checkbox at each step to track progress.

  1. 01

    Request access to the WDT Predictive Intelligence Teams channel for project details and documents.

    Request/contact method not specified Confirm with project lead.
  2. 02

    Request access to GitHub Enterprise using the provided URL: https://engineeringplatforms.deloitte.com/github-enterprise.

    Additional access-request/contact method not specified Confirm with project lead.
  3. 03

    Request access to Claude Code and Copilot from Natalie Lorati.

    Contact method not specified Confirm with project lead.
  4. 04

    Install Okta Verify on your mobile device and sign in using Deloitte credentials.

    Support/contact method not specified Confirm with project lead.
  5. 05

    Sign in to Deloitte CMS for ServiceNow and other environment access using the provided URL: https://deloittecms.digitalidentityservice.com/app/UserHome.

    Access-request/contact method not specified Confirm with project lead.
  6. 06

    Request access to cloud environments such as AWS, Databricks, and other tools needed for PI-related work from Manikandan Elangovan and Deepak Basnet.

    Contact method not specified Confirm with project lead.
